# 🇱🇰 Ceylon Echo — Sri Lankan Heritage Audio Guide

**Ceylon Echo** is a cross-platform mobile application built with React Native and Expo, designed to showcase Sri Lankan heritage sites through multilingual audio guides, immersive storytelling, and localized experiences.

---

## 🚀 Key Features

* **🌐 Multilingual Content Pipeline:** Fully integrated English (`en`), French (`fr`), and Chinese (`zh`) language support with dynamic locale fallback and `AsyncStorage` persistence.
* **🎧 Multilingual Audio Guides:** Language-specific audio streaming and attraction descriptions managed through a unified admin panel and Cloudinary media pipeline.
* **🏛️ Custom Heritage UI & Branding:** Custom heritage branding assets (`ce-logo.png`), parchment styling, and polished player/admin interfaces.
* **📱 Cross-Platform Testing:** Configured with EAS Build for physical Android device testing (`.apk` preview builds).

---

## 🛠️ Tech Stack

* **Frontend:** React Native, Expo, Expo Router
* **Backend & Storage:** Firebase (Firestore / Storage) & Cloudinary Media Pipeline
* **Build Tools:** EAS CLI (Expo Application Services)
